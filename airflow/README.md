# Apache Airflow 餐廳預定系統用配置指南

本目錄包含 Apache Airflow DAG（有向無環圖）和配置文件，用於自動畫餐廳預定管理任務。

## 📋 項目範圍

Apache Airflow 是一個工作流編排平台，可幫助自動化餐廳預定應用中的重複性任務。本項目包括三個主要的 DAG：

### ✨ Airflow 的主要作用

- **📅 DAG 排程管理**：在 UI 中查看所有 DAG（工作流）的排程，確保任務在正確的時間執行。

- **⏱️ 手動觸發測試**：方便在開發或測試階段直接手動觸發 DAG，驗證流程是否正確。

- **📊 任務監控與日誌**：Airflow 提供任務執行狀態與詳細日誌，讓您能快速定位錯誤或性能瓶頸。

- **📧 自動化通知**：當任務完成或需要通知客戶時，可自動發送電子郵件，減少人工操作。

- **💾 數據庫備分**：通過定時任務，自動執行每日數據庫備份，確保數據安全。

- **📝 報表生成**：定期生成預定或業務報表，支持決策與運營分析。

- **🔔 異常警示**：當任务失敗時，Airflow 會即時發送警示，避免錯誤被忽略。

---

## 🎯 三個核心 DAG 说明

### 1️⃣ **餐聽預定管理 DAG** (`restaurant_booking_dag.py`)

**功能说明**：管理日常預定操作

- ✅ **自動確認預定**：自动確認超過 24 小时未確認的待定預定
- ❌ **自動取消過期預定**：取消過期且未被確認的預定
- 📊 **生成日報**：生成每日預定報告，便於運營分析
- 📍 **檢查桌位可用性**：實時檢查餐廳桌位狀態

**執行频率**：每小时執行一次

---

### 2️⃣ **預定通知 DAG** (`booking_notifications_dag.py`)

**功能说明**：發送自動化電子郵件通知

- 🔔 **提前提醒**：在預定時間前 24 小時發送提醒邮件
- ✉️ **确認通知**：新確認的預定立即發送確認郵件
- 📬 **取消通知**：預定被取消時發送取消通知

**執行頻率**：每天上午 9 點和下午 5 點執行

---

### 3️⃣ **數據庫備份 DAG** (`data_backup_dag.py`)

**功能說明**：執行定期數據庫維護和備份

- 💾 **創建數據庫備份**：完整備份 PostgreSQL 數據庫
- 📦 **备份媒体文件**：備份上傳的圖片和其他媒體文件
- ✔️ **驗證備份完整性**：確保備份文件可用且未損壞
- 🧹 **清理舊備份**：自動删除 7 天以前的備份文件，節省存儲空間

**執行頻率**：每天凌晨 2 點執行一次

---

## 🚀 快速開始指南

### 📋 系统要求

- **Python 版本**：3.8 或更高版本
